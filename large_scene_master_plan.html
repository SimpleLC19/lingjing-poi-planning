二、七大生态分区（Zones）
以「万古灵树」为世界脉心，六大分区环绕共生，形成完整生态循环
Z1
灵脉核心区
CORE SANCTUM
神秘圣地
大陆心脏：万古灵树根系贯穿整座山脉，灵脉能量从这里流向所有分区。设有低干扰缓冲带，是全世界的生态与叙事原点。
POI · 万古灵树 / 灵脉祭坛 / 圣殿遗迹 / 灵泉石窟
Z2
飞瀑流域区
CASCADE BASIN
自然人文
水系统核心：多层蓝色发光瀑布群 + 山腰村落带 + 梯田水系，承担供水、观景与聚落生活，是"活着的"生态人文复合区。
POI · 飞瀑流光 / 山村秘境 / 蓝瀑天梯 / 灵泽湖
Z3
云海高地区
CLOUD ALPINE
自然观景
海拔 2,000–2,800m 的高山气候带：翻涌云海 + 风化岩峰 + 仙塔遗迹。气候边界带来强烈视觉留白，是"呼吸感"担当。
POI · 云海观景 / 仙塔远眺 / 天风台 / 雪线回廊
Z4
浮空群岛区
SKY ARCHIPELAGO
神秘观景
悬浮岩体 + 天空生物带，垂直维度奇观。通过浮岛锚链与风舟航线连接，夜晚的浮岛灯光是大陆的"天空星座"。
POI · 浮岛幽境 / 星灯码头 / 风脊巢穴 / 空鲸航道
Z5
古林花海带
ANCIENT BLOOM
自然生态保育
大陆绿肺：万年古木 + 紫晶花海 + 苔原栈道。四季轮作的花田与生物廊道相连，是生物多样性与生态研学核心区。
POI · 紫晶花海 / 古木栈道 / 苔光湿地 / 守望林线
Z6
幽暗洞窟区
GROTTO UNDERLAND
神秘暗线
地下 800–1,200m 的溶洞体系：发光菌毯、地下暗河与灵矿脉。承载秘境的传说暗线，是探索型玩家的深度目标区。
POI · 灵泉石窟 / 荧光菌谷 / 地下灵河 / 矿脉回廊
Z7
边缘守望带
FRONTIER WATCH
人文观景
大陆边界：守望者之台 + 古长城 + 结界门扉。第一印象的观景入口，也是大陆与外界之间的缓冲与仪式感地带。
POI · 守望者之台 / 结界门扉 / 古长城 / 晨昏广场

六、叙事与探索深度（三层结构）
从"看见"到"沉浸"再到"发现"，层层递进的设计逻辑

表层 · 看见（First Sight）

面向大众的观景主线：Z7 晨昏广场 → Z5 花海 → Z2 山村 → Z1 神树。低门槛、高景观密度，2–4 小时可完成，覆盖 70% 游客。

中层 · 沉浸（Immersion）

面向深度游客的体验主线：Z3 云海 → Z4 浮岛 → 风舟夜航 → Z1 祭坛。加入互动装置、声光表演、夜间星空联动，1 日行程。

内层 · 发现（Discovery）

面向探索玩家的暗线主线：Z1 石窟 → Z6 地下灵河 → 矿脉回廊 → 荧光菌谷。解谜、传说、隐藏叙事，需提前预约，限流保护。
